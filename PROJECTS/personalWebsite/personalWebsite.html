Build a Personal Website

Create a personal website and host it for free with GitHub Pages, then optionally put it on your own domain through Cloudflare. This guide uses Visual Studio Code and needs no frameworks or build tools.

Last reviewed October 2026

Requirements

  • GitHub account (free)
  • Git
  • Visual Studio Code
  • Cloudflare account (optional)
  • A domain registrar (optional)

Steps

01Create a GitHub Repository

  1. Sign in to GitHub.
  2. Click the + menu in the top-right corner and choose New repository.
  3. Name the repository. If you name it yourusername.github.io, your site is served from https://yourusername.github.io. Any other name, such as personal-website, is served from https://yourusername.github.io/personal-website.
  4. Set the visibility to Public. On a free GitHub plan, Pages only works for public repositories.
  5. Turn on Add README so the repository starts with a first commit.
  6. Click Create repository.

02Install and Configure Git

  1. Install Git:
    • Windows: download the installer from git-scm.com, or run winget install --id Git.Git -e. The installer includes Git Bash.
    • macOS: run xcode-select --install, or brew install git if you use Homebrew.
    • Linux: use your package manager, for example sudo apt install git or sudo dnf install git.
  2. Open a terminal (Git Bash on Windows) and set your name and email. Use the email on your GitHub account, or your GitHub noreply address if you keep your email private:
    • git config --global user.name "Your Name"
    • git config --global user.email "you@example.com"

If you turned on "Keep my email addresses private" in GitHub, pushes that use your real email are rejected. Find your noreply address under GitHub Settings → Emails.

03Clone Your Repository

  1. Open VS Code.
  2. Click the Accounts icon at the bottom of the Activity Bar on the left and sign in with GitHub.
  3. Open the Explorer with Ctrl + Shift + E (Cmd + Shift + E on macOS) and click Clone Repository. You can also open the Command Palette and run Git: Clone.
    • Choose Clone from GitHub and pick your repository, or paste its URL.
    • Choose a folder to save it in.
    • Click Open when VS Code asks whether to open the cloned repository.

04Create Your Website

  1. In the Explorer, click the New File icon, or right-click an empty area and choose New File.
  2. Name the file index.html. GitHub Pages serves this file as your home page.
  3. Add the following code and save the file: 
    <!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Personal Website</title>
  </head>
  <body>
    <h1>Welcome to My Personal Website!</h1>
  </body>
</html>

05Commit and Push Your Changes

  1. Open Source Control with Ctrl + Shift + G (Cmd + Shift + G on macOS).
  2. Click the + next to your changes to stage them.
  3. Type a commit message, such as Add home page.
  4. Click Commit.
  5. Click Sync Changes to push your commit to GitHub.

06Turn On GitHub Pages

  1. Open your repository on GitHub and click the Settings tab.
  2. In the left sidebar, under Code and automation, click Pages.
  3. Under Build and deployment, set Source to Deploy from a branch.
  4. Under Branch, choose main and the / (root) folder, then click Save.
  5. Wait a minute or two. Refresh the Pages settings and click Visit site when the link appears. You can follow the deployment under the repository's Actions tab.

Every push to main now redeploys your site automatically.

07Buy a Domain Name Optional

  1. Go to a domain registrar such as Cloudflare Registrar, Porkbun, or Namecheap.
  2. Search for the domain you want.
  3. Purchase it. Compare the renewal price as well as the first-year price, since they often differ.

If you buy the domain through Cloudflare Registrar, it already uses Cloudflare's nameservers, so you can skip to step 09.

08Move Your Domain's DNS to Cloudflare Optional

  1. Create a free Cloudflare account and sign in to the dashboard.
  2. Choose to add (onboard) a domain, then enter your domain name.
  3. Let Cloudflare scan for existing DNS records and review what it finds.
  4. Select the Free plan.
  5. Cloudflare shows you two nameservers. Copy them.
  6. At your registrar, open the domain's nameserver settings, choose custom nameservers, and replace the existing ones with Cloudflare's two.
  7. Back in Cloudflare, continue and click Check nameservers. Cloudflare emails you when the domain is active.

Nameserver changes often finish within an hour, but can take up to 24 to 48 hours.

09Connect Your Domain to GitHub Pages Optional

  1. In Cloudflare, open your domain and go to DNS → Records.
  2. Add four A records with the name @ (your root domain), one for each GitHub Pages IP address:
    • 185.199.108.153
    • 185.199.109.153
    • 185.199.110.153
    • 185.199.111.153
  3. Optionally, add four AAAA records for IPv6: 2606:50c0:8000::153, 2606:50c0:8001::153, 2606:50c0:8002::153, and 2606:50c0:8003::153.
  4. Add a CNAME record with the name www and the target yourusername.github.io. Use your GitHub Pages address here, not your custom domain.
  5. Set the proxy status on these records to DNS only (grey cloud) for now, so GitHub can issue your HTTPS certificate.
  6. In your repository, go to Settings → Pages, enter your domain under Custom domain, and click Save. GitHub runs a DNS check.
  7. Once the certificate is ready, tick Enforce HTTPS.
  8. To prevent domain takeovers, verify the domain under your GitHub profile's Settings → Pages by adding the TXT record GitHub gives you.

The HTTPS certificate can take up to 24 hours to issue. If you later turn on Cloudflare's proxy (orange cloud), set Cloudflare's SSL/TLS mode to Full to avoid redirect loops.
